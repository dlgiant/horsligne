# Metrics & 90-Day Timeline

## Success metrics (targets)
| Metric | Target | Source |
|---|---|---|
| Waitlist → paid conversion | ≥ 10% | landing page + payments |
| CAC payback | ≤ 2 sessions | marketing spend / revenue |
| Show-up rate | ≥ 85% | staff app check-ins |
| On-time check-outs (no overdue) | ≥ 80% of sessions | checkpoint log |
| Safety incidents | 0 | incident reports |
| Families active on portal | ≥ 70% of trips with contacts | portal audit log |
| Message delivery at check-out | 100% | checkpoint log |
| Activity bookings per trip | ≥ 0.5 | Explore & book |
| Activity commission revenue | tracked | payments |
| Repeat booking ≤ 30 days | ≥ 40% of participants | client app |
| Post-session rating | ≥ 4.5/5 | in-app survey |
| Wellbeing delta (pre/post) | positive trend | questionnaires |

## 90-day timeline
| Weeks | Work |
|---|---|
| 1–2 | Brand + landing page (PT/EN) + waitlist; pricing; trust pack drafted; recruit + vet facilitators for launch town; buy satellite communicator for remote venues |
| 3–6 | Build client app (Flutter), staff app (offline-first), portal, admin console; two internal dry-runs, one fully offline (airplane mode) |
| 7 | Record 3-min walkthrough + run 30-min live demo (`02-demo-script-30min.md`); launch landing page; convert waitlist → first paid bookings |
| 8–11 | First real sessions; collect wellbeing data, reviews, portal audit data; iterate on flow + copy |
| 12 | Metrics review vs targets; pick next town; decide whether to open organizer B2B channel (camps/schools) |

## Demo-day success criteria (week 7)
- Audience can repeat the model back correctly
- Test family contact completes portal login + sends message without help
- Full offline dry-run passes
- Waitlist signups same day; ≥10% convert within 2 weeks
