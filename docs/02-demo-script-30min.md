# 30-Minute Demo Script — "Phone-free abroad, family in the loop"

D2C audience: travelers + family members watching live. All demo data fictional.

## Cast and materials
- **Presenter:** narrates, drives the laptop
- **Traveler device:** phone, client app, logged in as "Ana Lima"
- **Facilitator device:** phone/tablet, staff app, logged in as "Rafa (facilitator)"
- **Family laptop:** browser, portal, logged in as "Carlos (brother, Lisbon)"
- **Props:** sealed phone pouch + claim-code card, printed check-out slips, satellite communicator
- **Demo data:** Trip "Chapada Diamantina, 5 days". Session "Sunrise hike + meditation, 06:00–09:00 BRT". Family in Lisbon (dual timezone). Venue landline +55 75 3xxx-xxxx. Activity for gift demo: "Paddleboarding on Rio Lençóis, Sat 10:00, R$ 120, risk: low, guide: Marina (vetted ✓)".

## Pre-demo checklist (T-60 min)
1. Charge all devices to 100%; hotspot backup on presenter phone
2. Seed accounts (traveler, facilitator, portal contact); clear all notifications except the 3 demo ones
3. Run full flow once end-to-end; run again in airplane mode — if offline fails, don't demo live
4. Set demo session overdue grace to 2 minutes (admin override)
5. Print 3 check-out slips; stage pouch with code HD-4821
6. Record backup video of portal + check-out segments
7. Landing page + waitlist loaded in another tab
8. Test OTP on SMS and email paths

## Script

### 0:00–0:03 — The problem (laptop: landing page hero)
**Say:** "You're hiking in Chapada Diamantina. Your phone is the biggest theft target you're carrying — and your family back home is refreshing WhatsApp. Today: you go phone-free, they watch a calm status page instead of a read receipt."
**Show:** hero headline "Phone-free days abroad. Family stays in the loop. You stay safe."
**Takeaway:** the portal is for them; the detox is for you.

### 0:03–0:10 — Traveler side: book + register family (traveler phone, screen-shared)
1. Client app as Ana → Register trip → "Chapada Diamantina, Brazil" + dates
2. Add loved one "Carlos, brother, +351…" → portal link + password + OTP sent to Carlos's phone
3. Browse sessions → "Sunrise hike + meditation, 06:00–09:00, R$ 90" → pay by card (3DS) → confirmation
4. Show the only 3 notifications Ana gets: booking confirmation, "session starts in 30 min", "session ended / collect your phone"
**Say:** "No feed, no leaderboard, no reason to open this app during the hike. Booking happens on wifi — the session needs zero bars."

### 0:10–0:20 — Portal side: family view + Explore & book (family laptop)
1. Carlos opens link → password → OTP via SMS (email fallback) → logged in
2. Session card: status "Scheduled", 06:00–09:00 BRT / 10:00–13:00 Lisbon, "last synced 2 min ago"
3. Carlos sends routine: "Dad's flight delayed — new pickup 18:00 🌄" and urgent: "Mom fell at home — call us when you can"
4. Carlos opens **Explore — Chapada Diamantina** → filters water activities → "Paddleboarding, Sat 10:00, R$ 120, risk: low, guide vetted ✓" → **Book as a gift** → pays on his card
5. Cut to Ana's app: "🎁 Carlos gifted you: Paddleboarding, Sat 10:00 — Accept / Decline" → Accept → appears in her list and his portal with venue emergency channel
6. Show what Carlos does NOT see: no GPS, only "Venue: Pousada Chapada, Chapada Diamantina"
**Say:** "Families don't just watch — they can gift the trip. Booked ahead or mid-stay, it's the same loop: phone away, activity happens, everyone gets the check-out summary. And privacy runs both ways: status and city, never your location."

### 0:20–0:25 — Staff side: check-in, checkpoint, verification (facilitator phone)
1. Rafa opens staff app → roster: Ana, HD-4821 → Check in → phone custody "sealed pouch, code HD-4821" (hold up pouch) → status "In progress"
2. Sync: two messages appear, tagged routine / urgent
3. Verification demo: urgent triggers callback → Carlos's phone rings → confirms "real, relay after the hike" → marked "verified — relay at check-out" (life-threatening would interrupt)
4. Checkpoint log entries with timestamps
5. Run a 2-minute mini meditation — 20 seconds of real silence in the room
**Say:** "In remote venues with no signal the staff app works fully offline and syncs later. Emergencies go through the satellite communicator or venue landline — the portal always shows which channel that venue has."

### 0:25–0:28 — Overdue flag + check-out (family laptop, then facilitator phone)
1. Session passes expected check-out + 2-min demo grace → portal flips to "Overdue" → banner: "Venue emergency contact: +55 75 3xxx-xxxx"
**Say:** "Overdue is not an emergency — it's a prompt. If it persists, the family calls the venue number right there."
2. Rafa checks Ana out → slip prints/shows: "No emergency communications relayed. 1 routine message from Carlos: pickup 18:00. Phone-free: 3h 02m."
3. Portal: "Checked out, 09:02 BRT", message marked delivered, SMS queued to Ana for when she's back in coverage
4. Flash admin console: audit log (portal logins), checkpoint log, revenue per session

### 0:28–0:30 — Trust + CTA (landing page tab)
1. Trust pack: waiver, facilitator background checks, insurance certificates, LGPD, two-adult rule
2. Pricing + waitlist: "First session in your town 50% off"
3. 2–3 Q&A (below)

## Anticipated Q&A (<30s each)
- Real emergency, no signal? → Satellite SOS / venue landline per session; no channel = no session there.
- Who sees my location? → No one. Venue + city only; per-trip credentials expire.
- Family has no SMS abroad? → Email OTP; portal works on any browser.
- What if I don't check out? → 30-min grace, then "overdue" + venue number in portal.

## Contingency playbook
| Failure | Response |
|---|---|
| Wifi dies | Go airplane mode on purpose — "this is the product"; run offline, show sync on reconnect |
| OTP SMS fails | Switch to email OTP live |
| Portal won't load | Play recorded backup segment; continue on staff app |
| Overdue flag doesn't fire | Admin "simulate overdue" — never wait real time |
| Timing overrun | Cut overdue simulation (has recording backup) |
| Stuck | Close on trust pack + waitlist |

**Invite line:** "30 minutes: watch a traveler book a phone-free sunrise hike, her brother track it from Lisbon on a calm portal, gift her a paddleboarding lesson, and get an urgent message verified without interrupting the hike. Waitlist link at the end."
