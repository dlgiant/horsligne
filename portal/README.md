# portal/ — family portal (React web)

For loved ones at home. Per-trip access: unique link + password + OTP (SMS, email fallback), expiring at trip end + 24h, revocable by the traveler, fully audit-logged.

Shows: session status in dual timezone with "last synced", expected check-out + 30-min overdue flag with venue emergency contact, routine/urgent messaging with verification status, Explore & book (destination catalog; gift or propose bookings), check-out summary.

Never exposes GPS or precise location — venue + city only. PT/EN at launch.
